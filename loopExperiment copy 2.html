LOOP PROTOCOL: SUM OF ODD NUMBERS

BÀI TOÁN THỰC NGHIỆM:

Tính tổng của chuỗi số lẻ bắt đầu từ 1 đến số lẻ thứ $n$.

S = 1 + 3 + 5 + ... + (2n + 1)

THUẬT TOÁN MÔ PHỎNG:

Sử dụng vòng lặp FOR với biến chạy i đi từ 0 đến n. Mỗi bước lặp, giá trị cộng vào tổng $S$ là số hạng lẻ thứ $i$: $2i + 1$.

int S = 0;
for (int i = 0; i <= n; i++) {
  int odd = 2 * i + 1;
  S = S + odd;
}
